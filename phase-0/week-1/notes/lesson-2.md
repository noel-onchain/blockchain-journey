# Lesson 2 Notes

## Client vs server
- Client: the browser asks.


- Server: the other computer answers.



## What happens when I open a website
You type a URL.
The browser asks the server for that page.
The server sends the page back.
The browser draws it.




## What I saw in DevTools
- Request URL: https://github.com/
- Status code: 200 OK
- Method: GET

## HTTP vs HTTPS
HTTP/HTTPS = request/response between browser and server



## Why this matters for blockchain
Blockchain later uses P2P (computers talking to each other, not only client→one company server).

A hash is a fingerprint, not encryption.

A block in a blockchain stores the hash of the previous block, so changing old data changes every hash after it.
